## 🧠 Style Fusion Guide

Melao's Studio uses this to build Suno prompts like:

```
"Bad Bunny emotional Latin trap + Carole King confessional piano"
→ Suno: "dark Latin trap with live piano, emotional male vocals, 
   introspective lyrics, 808s meets acoustic, bilingual Spanish-English"

"Daddy Yankee street anthem + Celia Cruz Afro-Cuban energy"  
→ Suno: "reggaeton dembow with Afro-Cuban percussion, salsa horns,
   high energy, street anthem, tropical party vibes"

"Taylor Swift narrative + Romeo Santos bachata"
→ Suno: "bachata with confessional storytelling lyrics, guitar, 
   romantic, heartbreak, bilingual, cinematic narrative"
```
